# O7 Drum Project — student practice tools

- `game/` — O7 Rhythm Game (write the rhythm, earn badges)
- `trainer/` — O7 Rhythm Trainer (play along, compose)
- `index.html` — front page linking to both

Each folder is a self-contained `index.html`. Published with GitHub Pages from `main` / root:
https://o7drumproject.github.io/training/
